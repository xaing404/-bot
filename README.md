# TedaBot — 微信多场景智能体机器人

基于 **wxauto4**（Windows UI 自动化）+ **OpenAI 兼容接口** 的微信群聊/私聊智能体。
支持多场景独立记忆、角色扮演、主动互动与群静默接话，不受网页协议限制，
任何可登录 PC 微信（4.x）的账号均可使用。

## 功能特性

### 消息处理
- 群聊/私聊消息监听：捕获内容、发送者、时间戳，双保险去重（id 指纹 + 内容指纹）
- 关键词触发：精确匹配 + 模糊匹配（相似度阈值可调）
- @机器人触发：消息属性 + 文本双重判定，享最高优先级，绕过回复冷却
- @提及精准过滤：AI 只看到纯文本问题（兼容微信 U+2005 特殊空格），
  不会把 `@机器人昵称` 误解析为对话对象；正文中的邮箱等 `@` 不受影响
- 多消息拆分发送：回复按换行拆为多条消息逐条发送（条间停顿可配），模拟真人连发

### 多场景记忆系统
- 场景键 `group:<群名>` / `private:<昵称>`，群聊与私聊记忆**完全隔离**（含同名情况）
- 场景记忆持久化：每场景一个 JSON 文件，原子写入，重启自动恢复
- 场景级防刷屏：私聊/群聊独立最小回复间隔，@回复、普通回复、主动发言共享冷却计时
- 并发安全：每场景一把线程锁（同场景串行、跨场景并发）

### 主动互动引擎
- 三种模式：`keyword` 只关键词回复 / `context` 只上下文主动 / `hybrid` 混合
- 三种触发策略（可叠加）：
  - **消息阈值**：每累计 N 条群消息后主动跟一句话题
  - **活跃度冒泡**：超过最大间隔且群里有新消息时冒泡
  - **群静默接话**：超过 `silence_interval` 无任何成员发言时，基于上下文自动接话；
    任一成员发新消息立即重置计时
- 质量保障：与近期内容相似度过高即丢弃、敏感词过滤、每日/每周发言上限

### 可靠性与可观测性
- **串行发送队列**：所有回复统一入队，专职线程按序发送（优先级：@回复 > 普通回复 > 主动发言），
  单条完整发完才发下一条，杜绝多回复乱序/穿插；异常隔离不阻塞队列
- **UI 互斥锁 + 窗口身份校验**：微信窗口的读写操作全程串行化，读取前校验当前窗口
  会话身份，杜绝主窗口模式下消息归属错乱（跨群状态污染）
- **发送看门狗**：单条消息发送超 30 秒自动告警，卡死可从日志立即定位
- **状态监控**：周期输出各活跃场景的记忆条数、回复次数、发送队列指标
- watchdog：主循环异常自动重启（连续崩溃 10 次停止）；退出前冲刷发送队列不丢消息

## 环境要求

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows 10/11 |
| Python | 3.9 - 3.12 |
| 微信 PC 客户端 | **4.x**（wxauto4 免费版最高支持 4.1.8.107） |
| 网络 | 可访问所选 AI 接口 |

> 注：微信已强制升级至 4.x，老的 wxauto（3.9.11 方案）已废弃，本项目使用 wxauto4。

## 快速开始

1. **克隆并安装依赖**

   ```powershell
   git clone https://github.com/xaing404/-bot.git
   cd -bot/teda_bot
   pip install -r requirements.txt
   ```

2. **创建配置文件**

   ```powershell
   Copy-Item config.example.yaml config.yaml
   ```

   编辑 `config.yaml`，至少填写：
   - `ai.base_url / api_key / model`：你的 AI 接口信息
   - `wechat.group_whitelist`：允许响应的群名（与微信显示**完全一致**）
   - `wechat.private_whitelist`：需要监听的私聊好友昵称
   - `bot.name` 可留空：自动读取你的微信昵称用于 @识别

3. **启动**

   ```powershell
   python .\main.py
   ```

4. **强烈建议：在微信中双击白名单群聊，打开独立聊天窗口**
   - 有独立窗口：机器人直接轮询该窗口，不干扰主窗口正常使用，
     消息归属、发送可靠性、响应速度均最优
   - 无独立窗口：机器人轮换切换主窗口拉取/发送消息（已做互斥锁与身份校验），
     但仍建议不要同时手动操作微信主窗口

## 配置说明

### 触发规则（trigger）

| 配置 | 说明 |
|---|---|
| `keywords` | 群聊关键词列表，命中即回复（私聊默认不受限） |
| `fuzzy` / `fuzzy_threshold` | 模糊匹配开关 / 相似度阈值（0~1） |
| `reply_on_at` | 被 @ 时是否回复（最高优先级，绕过冷却） |
| `reply_private` | 私聊是否无需关键词直接回复 |
| `reply_at_sender` | 群聊回复是否在开头 @提问人 |
| `duplicate_threshold` | 与最近回复相似度 ≥ 该值时自动拦截 |

### 主动互动（proactive）

| 配置 | 说明 |
|---|---|
| `mode` | keyword / context / hybrid |
| `message_threshold` | 每累计多少条群消息后主动发言一次 |
| `min_interval` / `max_interval` | 两次发言最小间隔（防刷屏）/ 活跃度冒泡最大间隔 |
| `silence_interval` | 群静默接话时长（秒），无成员发言超时即接话；0 关闭 |
| `context_window` | 参与上下文分析的最近消息条数 |
| `daily_cap` / `weekly_cap` | 每日 / 每周主动发言上限 |
| `repeat_threshold` | 与近期内容相似度超过该值则放弃（防重复） |

### AI 接口（ai）

| 配置 | 说明 |
|---|---|
| `base_url` / `api_key` / `model` | OpenAI 兼容接口信息（OpenAI/DeepSeek/本地代理/ollama 等） |
| `max_context_rounds` | 每会话保留的最大对话轮数 |
| `context_max_age` | 上下文时间边界（秒），更早的历史不再带入 AI |
| `request_interval` | 两次 AI 请求最小间隔（秒） |
| `timeout` | 单次 AI 请求超时（秒） |
| `max_retries` / `retry_backoff` | 重试次数 / 指数退避基数 |

### 微信与发送（wechat）

| 配置 | 说明 |
|---|---|
| `poll_interval` | 消息轮询间隔（秒） |
| `dedup_window` | 消息去重时间窗（秒） |
| `send_queue_size` | 发送队列容量，满时丢弃新消息并告警 |
| `multi_message_delay` | 多条消息连发的条间停顿（秒），0 无停顿 |
| `group_whitelist` / `private_whitelist` | 监听的群聊 / 私聊白名单（名称须完全一致） |

### 其他

| 配置 | 说明 |
|---|---|
| `reply_interval.private` / `group` | 场景级最小回复间隔（秒），防刷屏 |
| `memory.enabled` / `dir` | 场景记忆持久化开关 / 存储目录 |
| `roles.default` / `roles.cards` | 默认角色卡名 / 角色卡定义（内联或 JSON 文件） |
| `safety.enabled` / `block_words` | 敏感词过滤开关 / 词表 |
| `logging.level` / `file` / `max_bytes` | 日志级别 / 路径 / 滚动大小 |

## 使用指南

### 触发方式一览

| 场景 | 触发方式 | 说明 |
|---|---|---|
| 群聊 | @机器人 | 最高优先级，立即回复并 @提问人 |
| 群聊 | 消息含关键词 | 精确/模糊匹配，受场景冷却限制 |
| 群聊 | 主动互动 | 阈值/活跃度/群静默三种策略自动触发 |
| 私聊 | 任意消息 | 默认直接回复（`reply_private: true`） |

### 角色卡

支持两种定义方式，`{bot_name}` 替换为机器人昵称，`{{user}}` 替换为发送者昵称：

```yaml
roles:
  default: "assistant"
  cards:
    assistant:                       # 方式一：内联定义
      name: "通用助手"
      prompt: "你是 {bot_name}，一个友好、简洁的中文聊天助手。"
    yandere:                         # 方式二：JSON 角色卡文件
      file: "角色卡_病娇.json"
```

JSON 角色卡兼容中英文键名（`name/角色名称`、`prompt/系统提示词`），
结构化角色卡（无整体提示词）会自动合成兜底 prompt（上限 5000 字）。

### 场景记忆

记忆文件按场景存储于 `memory/` 目录（已从 Git 排除，保护隐私）：

```
memory/
├── group_谁也没我们.json    # 键为 group:谁也没我们
├── private_张三.json        # 键为 private:张三
└── ...
```

删除对应文件即可清空某场景的记忆；关闭 `memory.enabled` 则仅存内存。

## 常见问题排查

| 现象 | 排查方向 |
|---|---|
| 启动报无法连接微信窗口 | 微信 4.x 已登录且**主窗口已打开**（不能只挂在托盘） |
| 不回复 | 检查群名/昵称与微信显示完全一致；消息需含关键词或 @机器人；查日志「捕获消息」 |
| 回复答非所问 | 检查上下文是否被陈旧话题污染（可删 `memory/` 对应场景文件重置）；`ai.context_max_age` 调小 |
| 消息发送卡住 | 日志出现「发送疑似卡住」时，优先为监听群**打开独立聊天窗口**；确认微信窗口未被最小化 |
| 群串台/归属错乱 | 日志出现「窗口切换校验失败」即为拦截记录；建议打开独立窗口根治 |
| AI 频繁超时 | 上游接口慢：调大 `ai.timeout`、减小 `max_retries`，或更换接口 |
| 主动发言太频繁 | 调大 `message_threshold`/`min_interval`，或 `silence_interval` 设 0 |
| 程序反复重启 | 查看日志末尾异常栈；连续崩溃 10 次会自动停止 |
